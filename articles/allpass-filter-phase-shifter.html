第一章 全通滤波器总论

在信号处理领域，有一类特殊的电路：它对所有频率的信号都"一视同仁"地通过，增益恒为1（0dB），既不放大也不衰减——这就是全通滤波器（All-Pass Filter）。然而，"全通"这个名字极具误导性，因为它真正的功能并非"通过"，而是移相——只改变信号的相位，不改变信号的幅度。正因如此，很多工程师认为：全通滤波器真该改个名，叫移相器才对。

1.1 为什么叫"全通"又该改名

传统滤波器按功能可分为低通、高通、带通、带阻四类，它们共同的特点是对不同频率的信号有不同的增益——某些频率通过，某些频率被衰减。"全通滤波器"这个名字让人误以为它也是一种"滤波"器件，但事实是：它对所有频率的增益恒为1，根本不滤任何东西。

它唯一的功能是改变信号的相位，而且相移量随频率变化。因此，"移相器"（Phase Shifter）才是更准确、更直观的名称。在工程文献中，这两个名称常常混用，但理解电路本质时，务必记住：全通滤波器 = 移相器，核心功能是移相而非滤波。

教学类比：想象一个透明的玻璃棱镜——光线穿过时亮度不变（增益=1），但方向发生了偏折（相移）。全通滤波器就是电路中的"棱镜"，信号穿过时幅度不变，但相位发生了偏转。

1.2 传递函数与特征参数

一阶全通滤波器的标准传递函数为：

$$G(s) = \frac{Ts - 1}{Ts + 1}$$

其中 $T$ 为时间常数，决定了电路的频率特性。这个传递函数虽然形式简单，但蕴含着丰富的物理含义。下面逐一分析其核心参数。

参数表达式物理含义
增益 $K$$K = 1$（即 $20\lg K = 0\text{dB}$）输出幅度始终等于输入幅度，与频率无关
特征角频率 $\omega_0$$\omega_0 = \dfrac{1}{T}$相移为90°时的角频率，是移相特性的中心参考点
特征频率 $f_0$$f_0 = \dfrac{1}{2\pi T}$以Hz为单位的特征频率，工程中更常用
相移范围$180° \to 0°$低频时相移接近180°，高频时趋近0°，单调递减
$f_0$ 处相移$\varphi(\omega_0) = 90°$在特征频率点，相移恰好为90°
易混淆点：注意分子是 $Ts - 1$，不是 $1 - Ts$！这个负号的位置决定了相频特性的方向。如果写成 $G(s) = \frac{1 - Ts}{1 + Ts}$，虽然增益仍为1，但相移方向相反（从0°到-180°），对应的是滞后型移相器。

1.2.5 从传递函数到特征参数：完整推导路径

📖 前置阅读：本节涉及的复数辐角、arctan 象限修正等基础知识，已在姊妹篇《从欧拉公式到传递函数》的 1.3b 节（arctan象限修正法则）和 1.6 节（极坐标实例化·全通滤波器相位差）中系统讲解。建议先阅读该文再回到本节，理解会更顺畅。本节保留完整推导以保持自洽性。

上面的表格给出了传递函数的所有特征参数，但你可能会问：这些信息究竟是怎么从 G(s) 一步步推出来的？本节将给出完整的推导路线图，让你看到每一条结论的"来路"。

推导总览：整个推导只有一个出发点——$G(s) = \frac{Ts-1}{Ts+1}$，只有一个核心操作——令 $s = j\omega$ 代入频域分析。所有参数都是这两个步骤的自然推论。

步骤一：令 s = jω，进入频率域

传递函数在 s 域，要分析频率特性，必须代入 $s = j\omega$：

$$G(j\omega) = \frac{j\omega T - 1}{j\omega T + 1}$$

这是所有后续推导的唯一出发点。无论推导增益、特征频率还是相移，都从这个表达式开始。

步骤二：引入 ω₀ = 1/T，标准化表达

令 $\omega_0 = 1/T$（即 $T = 1/\omega_0$），代入上式：

$$G(j\omega) = \frac{j\frac{\omega}{\omega_0} - 1}{j\frac{\omega}{\omega_0} + 1} = \frac{-1 + j\frac{\omega}{\omega_0}}{1 + j\frac{\omega}{\omega_0}}$$
为什么引入 ω₀？引入 $\omega_0$ 后，所有频率都以 $\omega_0$ 为参考归一化了，$\omega/\omega_0$ 成为无量纲比值，物理含义更清晰——它就是"当前频率是特征频率的几倍"。这一步直接给出表中第二、三行：$\omega_0 = 1/T$，而 $f_0 = \omega_0/(2\pi) = 1/(2\pi T)$。

特征频率 $\omega_0$ 的物理本质是分母的转折频率——分母 $1 + j\omega/\omega_0$ 在 $\omega = \omega_0$ 时，实部和虚部相等，这是频率特性的关键分界点。就像低通滤波器的截止频率一样，$\omega_0$ 定义了全通滤波器相频特性的"中心"。

步骤三：推导增益 K = 1

取 $G(j\omega)$ 的模，分子模和分母模分别计算：

$$|\text{分子}| = \left|-1 + j\frac{\omega}{\omega_0}\right| = \sqrt{(-1)^2 + \left(\frac{\omega}{\omega_0}\right)^2} = \sqrt{1 + \left(\frac{\omega}{\omega_0}\right)^2}$$
$$|\text{分母}| = \left|1 + j\frac{\omega}{\omega_0}\right| = \sqrt{1^2 + \left(\frac{\omega}{\omega_0}\right)^2} = \sqrt{1 + \left(\frac{\omega}{\omega_0}\right)^2}$$

分子和分母的模完全相等！根本原因在于分子的 $(-1)$ 平方后等于 $(+1)$，与分母的 $(+1)$ 完全抵消。因此：

$$|G(j\omega)| = \frac{\sqrt{1 + (\omega/\omega_0)^2}}{\sqrt{1 + (\omega/\omega_0)^2}} = 1 \quad\Rightarrow\quad K = 1,\; 20\lg K = 0\text{dB}$$
表中第一行得证：增益 $K = 1$（0dB），与频率无关。这是"全通"的数学根源——分子分母模恒等，无论 $\omega$ 取什么值。

步骤四：推导相频特性公式

相移 = 分子辐角 − 分母辐角。要计算辐角，首先要掌握复数辐角的 arctan 计算法则——这是本步骤的前置知识，也是极容易踩坑的地方。

前置知识：复数辐角的 arctan 计算法则

任意复数 $a + jb$ 的辐角为 $\theta = \arctan(b/a)$，但 arctan 函数的值域只有 $(-90°, +90°)$，而复数辐角的范围是 $(-180°, +180°)$。因此必须根据实部 $a$ 的正负号判断象限，对 arctan 结果进行修正：

象限实部 $a$虚部 $b$辐角公式角度范围
第一象限$a > 0$$b > 0$$\theta = \arctan\dfrac{b}{a}$$0° \sim 90°$
第二象限$a < 0$$b > 0$$\theta = \pi - \arctan\dfrac{b}{|a|}$$90° \sim 180°$
第三象限$a < 0$$b < 0$$\theta = -\pi + \arctan\dfrac{|b|}{|a|}$$-180° \sim -90°$
第四象限$a > 0$$b < 0$$\theta = \arctan\dfrac{b}{a}$$-90° \sim 0°$
核心要点：只有实部为正（一、四象限）时，才能直接用 $\arctan(\text{虚部/实部})$；实部为负（二、三象限）时，arctan 给出的角度"偏了"，必须用 $\pi$ 去修正。
图1-0 arctan 函数值域图：只能覆盖 −90°~+90°，二、三象限需要 π 修正
常见误区：很多人以为辐角就是简单地 $\arctan(\text{虚部/实部})$，对任何复数都直接套这个公式。这在实部为负时会得到错误结果！例如 $-1 + j$ 的辐角是 $135°$，但直接算 $\arctan(1/{-1}) = \arctan(-1) = -45°$，差了 $180°$。正确做法是先算 $\arctan(1/1) = 45°$，再用 $\pi - 45° = 135°$。
教学类比：想象你站在原点看一个目标。arctan 只能告诉你目标"偏左还是偏右"的角度，但不知道目标在你"前面还是后面"。实部的正负号就是"前后"的判断——正号表示前面（直接看就行），负号表示后面（要转过身再看，所以需要 $\pi$ 修正）。

掌握了这个法则后，分别计算分子和分母的辐角：

分母：$1 + j\frac{\omega}{\omega_0}$

实部 $= +1 > 0$，虚部 $= \omega/\omega_0 > 0$，位于第一象限

实部为正，直接 arctan，无需修正：

$$\theta_D = \arctan\frac{\omega/\omega_0}{1} = \arctan\frac{\omega}{\omega_0}$$

分子：$-1 + j\frac{\omega}{\omega_0}$

实部 $= -1 < 0$，虚部 $= \omega/\omega_0 > 0$，位于第二象限

实部为负，必须用 $\pi$ 修正：

$$\theta_N = \pi - \arctan\frac{\omega/\omega_0}{|{-1}|} = \pi - \arctan\frac{\omega}{\omega_0}$$
对比理解：分母和分子的虚部相同（都是 $\omega/\omega_0$），arctan 的计算值也相同（都是 $\arctan(\omega/\omega_0)$），但因为实部一正一负，分母直接用，分子要用 $\pi$ 去减。这就是象限判定对辐角计算的影响——同一个 arctan 值，在不同象限给出完全不同的辐角。

总相移：

$$\varphi(\omega) = \theta_N - \theta_D = \left(\pi - \arctan\frac{\omega}{\omega_0}\right) - \arctan\frac{\omega}{\omega_0} = \pi - 2\arctan\frac{\omega}{\omega_0}$$

利用恒等式 $\arctan x + \arctan(1/x) = \pi/2$（$x > 0$），可以改写为更直观的形式：

$$\varphi(\omega) = 2\arctan\frac{\omega_0}{\omega}$$
两种形式等价：$\pi - 2\arctan(\omega/\omega_0)$ 和 $2\arctan(\omega_0/\omega)$ 完全等价，只是书写形式不同。改写后 $\omega_0/\omega$ 在 $\omega$ 增大时从 ∞→0，角度从 90°→0°，始终落在第一象限，物理直觉更清晰。后续分析统一使用 $2\arctan(\omega_0/\omega)$ 形式。

步骤五：推导相移范围 180° → 0°

将极限代入相频公式，验证两个极端情况：

频率条件代入计算结果物理含义
$\omega \to 0$（直流）$\varphi = \pi - 2\arctan(0) = \pi - 0$$180°$极低频时输出与输入反相
$\omega \to \infty$（高频）$\varphi = \pi - 2\arctan(\infty) = \pi - \pi$$0°$极高频时输出与输入同相
表中第四行得证：相移范围 $180° \to 0°$，单调递减。低频反相、高频同相——这是一阶超前移相器的标志性特征。

步骤六：推导 f₀ 处相移 = 90°

在 $\omega = \omega_0$ 时代入：

$$\varphi(\omega_0) = \pi - 2\arctan\frac{\omega_0}{\omega_0} = \pi - 2\arctan(1) = \pi - 2 \times \frac{\pi}{4} = \frac{\pi}{2} = 90°$$
表中第五行得证：在特征频率 $f_0$ 处，相移恰好为 90°——这是相移范围的中点。这一性质在工程设计中极为重要：只要知道目标频率和目标相移，就可以反算出所需的 $RC$ 时间常数。

推导路线图总结

表中参数推导关键步骤核心数学工具关键洞察

教学要点：整张参数表的五条信息，全部来自同一个推导链条：$G(s) \xrightarrow{s=j\omega} G(j\omega) \xrightarrow{\text{引入}\omega_0} \text{标准化形式} \xrightarrow{\text{取模}} K=1 \xrightarrow{\text{取辐角}} \varphi(\omega) \xrightarrow{\text{代入极限}} \text{范围与特殊点}$。理解了这个链条，你不需要死记硬背任何参数——它们都可以在几分钟内从传递函数重新推导出来。

1.3 幅频特性——恒定增益的证明

全通滤波器最显著的特征是增益恒为1，下面从传递函数出发严格证明这一点。

正弦稳态分析

在正弦稳态条件下，令 $s = j\omega$，并定义 $\omega_0 = 1/T$，传递函数变为：

$$G(j\omega) = \frac{-1 + j\frac{\omega}{\omega_0}}{1 + j\frac{\omega}{\omega_0}}$$

取模计算

分子的模：

$$\left|-1 + j\frac{\omega}{\omega_0}\right| = \sqrt{(-1)^2 + \left(\frac{\omega}{\omega_0}\right)^2} = \sqrt{1 + \left(\frac{\omega}{\omega_0}\right)^2}$$

分母的模：

$$\left|1 + j\frac{\omega}{\omega_0}\right| = \sqrt{1^2 + \left(\frac{\omega}{\omega_0}\right)^2} = \sqrt{1 + \left(\frac{\omega}{\omega_0}\right)^2}$$

分子与分母的模完全相等！因此对数幅频特性为：

$$L(\omega) = 20\lg|G(j\omega)| = 20\lg\frac{\sqrt{1 + (\omega/\omega_0)^2}}{\sqrt{1 + (\omega/\omega_0)^2}} = 20\lg 1 = 0\text{dB}$$
核心结论：全通滤波器的增益恒为0dB，与频率无关。根本原因在于分子的 $(-1)$ 经平方后变为 $(+1)$，与分母的 $(+1)$ 完全抵消。这保证了"只移相、不变幅"的特性。

1.4 相频特性——复平面向量推导

📖 前置阅读：复平面向量法分析传递函数相移的通用方法（模相除、角相减），在姊妹篇《从欧拉公式到传递函数》的 1.3 节（复数的两种表示）和 1.6 节（极坐标实例化·全通滤波器相位差）中有更系统的讲解。本节从全通滤波器的具体角度再演示一遍。

相频特性是全通滤波器的灵魂所在。用复平面向量法可以给出一种极其直观的推导，比纯代数方法更易理解。

复平面向量表示

将正弦稳态传递函数的分子和分母分别看作复平面上的向量：

  • 分子向量（蓝色）：$\vec{N} = -1 + j\frac{\omega}{\omega_0}$，实部 $= -1$（常数），虚部随 $\omega$ 变化
  • 分母向量（红色）：$\vec{D} = 1 + j\frac{\omega}{\omega_0}$，实部 $= +1$（常数），虚部随 $\omega$ 变化
图1-2 复平面向量分析：分子（蓝色）与分母（红色）向量

几何推导过程

  1. 绘制两个向量：在复平面上，分子向量从原点指向 $(-1, \omega/\omega_0)$，分母向量从原点指向 $(1, \omega/\omega_0)$。两个向量的虚部相同，实部关于虚轴对称。
  2. 识别相位关系：两个向量关于虚轴构成全等三角形，它们与虚轴的夹角相等。设分母向量与虚轴的夹角为 $\alpha$。
  3. 计算单个夹角：$\alpha$ 的正切值 = 对边/邻边 = $1 / (\omega/\omega_0)$，因此 $\alpha = \arctan(\omega_0/\omega)$。
  4. 求总相移：$G(j\omega)$ 的辐角 = 分子辐角 - 分母辐角。由对称性可知，两者与虚轴夹角相同，总相移恰好等于 $2\alpha$。
$$\varphi(\omega) = 2\arctan\frac{\omega_0}{\omega}$$
为什么要把 $\omega_0$ 放在分子？：原式 $\arctan(\omega/\omega_0)$ 在 $\omega$ 从0到无穷变化时，角度从0°变到90°。将参数倒置为 $\arctan(\omega_0/\omega)$ 后，角度从90°变到0°，始终落在第一象限，便于计算和分析。这是一种常用的数学处理技巧。

1.5 特殊频率点的相移验证

通过代入三个特殊频率值，可以验证相频特性的正确性：

频率条件$\omega/\omega_0$$\alpha = \arctan(\omega_0/\omega)$$\varphi = 2\alpha$物理含义
$\omega \to 0$（直流）$\to 0$$\arctan(\infty) = 90°$$180°$极低频时输出与输入反相
$\omega = \omega_0$（特征频率）$= 1$$\arctan(1) = 45°$$90°$特征频率处相移恰好90°
$\omega \to \infty$（高频）$\to \infty$$\arctan(0) = 0°$$0°$极高频时输出与输入同相
图1-3 全通滤波器相频特性：180°→0°单调递减

相频特性随频率增加从180°单调递减至0°，在特征频率 $\omega_0$ 处刚好过90°中点。这一对称而优雅的特性，使得移相器在工程设计中极具实用价值——只要知道目标频率和目标相移，就可以精确计算所需的RC时间常数。

第二章 超前移相器

理论模型建立之后，关键问题是：如何用实际电路实现这个传递函数？第一种实现形式是超前移相器——在差分放大器的基础上，将其中一个电阻替换为电容，实现频率相关的移相功能。

2.1 超前移相器的定义

超前移相器定义：输出信号的相角减去输入信号的相角大于0°，即 $\varphi_{out} - \varphi_{in} > 0$。输出信号在相位上"超前"于输入信号。

对于传递函数 $G(s) = \frac{Ts-1}{Ts+1}$，相频特性 $\varphi(\omega) = 2\arctan(\omega_0/\omega)$ 始终为正值（0°~180°），因此属于超前型移相器。这意味着在任意频率下，输出信号的相位都超前于输入信号。

2.2 电路结构与叠加分析

超前移相器的电路结构源自差分放大器，但将同相端的接地电阻替换为电容 $C$。关键特征是：同一个信号源 $U_r$ 同时接到同相端和反相端，因此本质上是多输入系统，需要用叠加原理分析。

图2-1 超前移相器电路结构

叠加分析步骤

虽然只有一个信号源 $U_r$，但它同时作用于同相端和反相端。根据叠加原理，分别计算每个输入端单独作用的输出，再将结果相加。

同相端单独作用

反相端信号置零（接地），$U_r$ 经 RC 分压后进入同相放大器。

  • 同相端电压：$U_+ = \dfrac{RCs}{RCs + 1} U_r$
  • 同相放大器增益：$1 + \dfrac{R_0}{R_0} = 2$
  • 同相端贡献：$U_{c1} = \dfrac{2RCs}{RCs + 1} U_r$

反相端单独作用

同相端信号置零（通过电阻接地），$U_r$ 经反相放大器。

  • 反相放大器增益：$-\dfrac{R_0}{R_0} = -1$
  • 反相端贡献：$U_{c2} = -U_r$
关键理解：同相端的 RC 分压网络是移相的核心——电容的阻抗 $1/sC$ 随频率变化，使得同相端分到的电压相位与频率相关。反相端的增益始终为 $-1$，不随频率变化。两者的叠加使得总输出呈现出全通特性。

2.3 传递函数推导

将同相端和反相端的贡献叠加：

$$U_c = U_{c1} + U_{c2} = \frac{2RCs}{RCs + 1}U_r - U_r$$

提取公因子 $U_r$ 并通分：

$$U_c = \left(\frac{2RCs}{RCs + 1} - 1\right)U_r = \frac{2RCs - (RCs + 1)}{RCs + 1}U_r = \frac{RCs - 1}{RCs + 1}U_r$$

令 $T = RC$，得到传递函数：

$$G(s) = \frac{U_c}{U_r} = \frac{Ts - 1}{Ts + 1}$$

这与全通滤波器的标准传递函数完全一致！证明超前移相器电路确实实现了全通滤波器的传递函数。

推导核心：关键步骤在于通分时 $2RCs - (RCs + 1) = RCs - 1$。分子中的 "$-1$" 来自反相端的 $-U_r$ 贡献，"$RCs$" 来自同相端 RC 分压产生的频率相关项。两者巧妙组合，构成了全通传递函数的分子。

第三章 滞后移相器

超前移相器的"镜像"就是滞后移相器——只需将 R 和 C 的位置互换，输出信号的相位就从"超前"变为"滞后"。这一章将详细分析滞后移相器的推导过程，特别关注传递函数中多出的那个"负号"对相频特性的深刻影响。

3.1 电路结构差异

滞后移相器与超前移相器的唯一区别：R 和 C 的位置互换。在超前移相器中，电容 C 在前（接信号源侧）、电阻 R 在后（接地侧）；在滞后移相器中，电阻 R 在前、电容 C 在后。

图3-1 滞后移相器电路结构（R和C位置互换）

超前移相器

  • 同相端：C 在前，R 在后
  • RC 分压在电容上取电压
  • 相移：$0° \sim +180°$（超前）

滞后移相器

  • 同相端：R 在前，C 在后
  • RC 分压在电容上取电压
  • 相移：$0° \sim -180°$（滞后）

3.2 传递函数推导

同样用叠加原理分析。反相端单独作用的结果不变：$U_{c2} = -U_r$。区别在于同相端的分压关系。

同相端分析

电阻在前、电容在后时，同相端电压取自电容上的分压：

$$U_+ = \frac{\frac{1}{sC}}{\frac{1}{sC} + R} U_r = \frac{1}{RCs + 1} U_r$$

经过同相放大器（增益=2），同相端贡献为：

$$U_{c1} = 2 \times \frac{1}{RCs + 1} U_r = \frac{2}{RCs + 1} U_r$$

叠加求总输出

$$U_c = U_{c1} + U_{c2} = \frac{2}{RCs+1}U_r - U_r$$

通分：

$$U_c = \frac{2 - (RCs + 1)}{RCs + 1}U_r = \frac{1 - RCs}{RCs + 1}U_r = -\frac{RCs - 1}{RCs + 1}U_r$$

令 $T = RC$，传递函数为：

$$G(s) = -\frac{Ts - 1}{Ts + 1}$$
关键差异：与超前移相器相比，滞后移相器的传递函数前面多了一个负号！这个负号是改变相频特性方向的根本原因。它使整个相频特性在超前型的基础上偏移了180°（或者说-180°），将正相移变成了负相移。

3.3 相频特性修正

超前移相器的相频特性为 $\varphi(\omega) = 2\arctan(\omega_0/\omega)$（0°~180°）。滞后移相器多了一个负号，相当于附加了 $-180°$ 的相移（负号在频域对应 $\pm 180°$ 的相位偏移，我们取 $-180°$）：

$$\varphi(\omega) = -180° + 2\arctan\frac{\omega_0}{\omega}$$

用频率表示：

$$\varphi(f) = -180° + 2\arctan\frac{1}{2\pi RCf}$$

特殊频率点验证

$\omega = \omega_0$$90°$$-180° + 90° = -90°$特征频率处滞后90°

第四章 工程设计与拓展

理论分析只是第一步，真正的工程师必须能将理论转化为实际电路。本章以50Hz滞后90°移相器的设计为例，完整展示从需求到参数计算到仿真验证的全过程，并分析实际工程中的误差来源和典型应用。

4.1 50Hz滞后90°移相器设计

设计需求

设计一个在50Hz频率点产生-90°相移的滞后移相器。

设计步骤

  1. 建立方程：滞后移相器相频特性为 $\varphi(f) = -180° + 2\arctan\frac{1}{2\pi RCf}$。要求在 $f = 50$Hz 处 $\varphi = -90°$，代入得：$-90° = -180° + 2\arctan\frac{1}{2\pi RC \times 50}$
  2. 化简方程：移项得 $2\arctan\frac{1}{2\pi RC \times 50} = 90°$，即 $\arctan\frac{1}{2\pi RC \times 50} = 45°$
  3. 去掉反正切：两边取正切，$\frac{1}{2\pi RC \times 50} = \tan 45° = 1$
  4. 求解 RC：$RC = \frac{1}{2\pi \times 50} = \frac{1}{314} \approx 3.18 \times 10^{-3}$ 秒
  5. 试凑标称值：依次代入标称电容值，计算对应的电阻：
    • $C = 10\text{nF}$ → $R = 318\text{kΩ}$（非标称值）
    • $C = 15\text{nF}$ → $R = 212\text{kΩ}$（非标称值）
    • $C = 22\text{nF}$ → $R = 145\text{kΩ}$（非标称值）
    • $C = 33\text{nF}$ → $R = 96.4\text{kΩ}$（接近100kΩ）
    • $C = 47\text{nF}$ → $R = 67.7\text{kΩ}$ → 取 $R = 68\text{kΩ}$（标称值）✅
  6. 确定最终参数：$R = 68\text{kΩ}$，$C = 47\text{nF}$，$R_0 = 10\text{kΩ}$
设计原则：电容标称值种类少（10/15/22/33/47nF），电阻标称值种类多（E24系列有24个值/decade）。因此先固定电容、再计算电阻，更容易找到接近的标称值组合。反过来先定电阻再算电容，很可能算出的电容值买不到。

5.2 常见误区辨析

误区一："全通滤波器就是让所有信号都通过的滤波器"

全通滤波器的核心功能不是"通过"信号（那只是一根导线就能做到的事），而是移相——改变信号的相位而不改变幅度。叫它"移相器"更准确。滤波器谱系中，它是唯一一个增益恒定的成员。

误区二："超前和滞后移相器只是相移方向不同，电路完全一样"

电路结构有关键差异：R和C的位置互换。这个看似微小的改变，导致同相端的分压关系不同，进而使传递函数多出一个负号，最终使相频特性整体偏移-180°。不是简单的"符号取反"，而是电路拓扑的根本变化。

误区三："滞后移相器的相频特性就是超前型的取负"

不完全对。滞后型的相频特性是 $\varphi = -180° + 2\arctan(\omega_0/\omega)$，而不是简单的 $-2\arctan(\omega_0/\omega)$。两者差了180°的偏移量，这是因为传递函数中的负号在频域对应 $\pm 180°$ 的相位贡献。取 $-180°$ 是为了使相移从0°开始（低频同相），到 $-180°$ 结束（高频反相），物理意义更明确。

误区四："叠加原理只适用于不同信号源的电路"

叠加原理适用于多个激励同时作用的线性电路，而不管这些激励是否来自同一个信号源。移相器中虽然只有一个信号源 $U_r$，但它同时作用于同相端和反相端，等效于两个独立激励。分别计算每个激励的响应再叠加，是完全正确的分析方法。

5.3 自测题

题目1：全通滤波器的增益为什么恒为0dB？请从传递函数出发证明。
传递函数 $G(j\omega) = \frac{-1+j\omega/\omega_0}{1+j\omega/\omega_0}$。分子模 $= \sqrt{1+(\omega/\omega_0)^2}$，分母模 $= \sqrt{1+(\omega/\omega_0)^2}$，两者相等（因为 $(-1)^2 = 1^2 = 1$），所以 $|G(j\omega)| = 1$，即 $L(\omega) = 20\lg 1 = 0$dB。关键在于分子的负号经平方后被消除。
题目2：超前移相器中，同相端的分压公式是 $\frac{RCs}{RCs+1}$ 还是 $\frac{1}{RCs+1}$？为什么？
超前移相器中，C在前R在后，同相端取电阻上的分压（电阻靠近运放同相端），因此 $U_+ = \frac{R}{R+1/(sC)} U_r = \frac{RCs}{RCs+1} U_r$。如果是滞后移相器（R在前C在后），同相端取电容上的分压，则 $U_+ = \frac{1/(sC)}{R+1/(sC)} U_r = \frac{1}{RCs+1} U_r$。分压关系取决于元件的连接顺序。
题目3：设计一个在1kHz处超前90°的移相器，如果选用 $C = 10\text{nF}$，电阻 R 应取多大？
超前90°意味着在 $f_0 = 1$kHz 处相移为90°（超前型的中点），因此 $f_0 = 1000$Hz。由 $f_0 = 1/(2\pi RC)$，得 $RC = 1/(2\pi \times 1000) = 159\mu$s。取 $C = 10$nF，则 $R = 159\mu\text{s} / 10\text{nF} = 15.9\text{k}\Omega$，取标称值 $R = 16\text{k}\Omega$。
题目4：滞后移相器的传递函数 $G(s) = -\frac{Ts-1}{Ts+1}$，其中负号对相频特性有什么影响？
负号在频域对应 $-180°$（或 $+180°$）的相位贡献。我们取 $-180°$，因此滞后移相器的相频特性为 $\varphi = -180° + 2\arctan(\omega_0/\omega)$。这使得：低频时 $\varphi = -180°+180° = 0°$（同相），高频时 $\varphi = -180°+0° = -180°$（反相），$f_0$ 处 $\varphi = -90°$（滞后90°）。整个相移范围从0°到-180°，输出始终滞后于输入。
题目5：为什么设计移相器时要"先选电容、再算电阻"，而不是反过来？
因为电容的标称值种类非常有限（常用的只有10/15/22/33/47nF等少数几个值），而电阻的标称值种类很多（E24系列有24个值/decade，E96系列更多）。如果先定电阻再算电容，很可能算出的电容值不在标称值范围内，买不到合适的电容。先定电容再算电阻，更容易找到接近的标称电阻值，且电阻还可以通过串联/并联进一步微调。
