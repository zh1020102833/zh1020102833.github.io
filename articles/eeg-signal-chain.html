2.2 不要混用 ENOB、Noise-Free Bits 与 LSB

常见误区：把 LSB、Noise-Free Bits、ENOB 当成一回事。对 EEG 这种低频微弱信号，最该先看的是 输入参考噪声 和在目标增益下的 噪声自由动态范围。
输入参考 LSB（以 G=24 为例）
ADC 核心 LSB ≈ 2 × VREF / 224 = 9.0V / 16777216 ≈ 0.536 μV（差分 ADC 满量程 ±VREF，用齐 24-bit 码宽）
折算到输入端 = 0.536 μV / 24 ≈ 22.4 nV/LSB
意义 ：码宽已经足够细，系统瓶颈通常不是量化，而是电极噪声、前端噪声和工频残余

为什么 LSB 和 Noise-Free Bits 里都有「×2」？

Noise-Free Bits（更适合 EEG 立项阶段）
输入满量程（G=24） ≈ 2 × 4.5V / 24 = 375 mVpp
输入参考噪声 ≈ 1 μVpp
噪声自由码数 ≈ 375mVpp / 1μVpp = 3.75×105
Noise-Free Bits ≈ log2(3.75×105) ≈ 18.5 bits
提示 ：这里不能直接称作 ENOB。ENOB 应由正弦输入下的 SINAD 推导，而 EEG 设计更常直接比较输入噪声和 noise-free resolution

3.2 输入保护电路

为什么必须加输入保护？

ADS1299 和斩波运放（ADA4522-1）均为 MOS 输入，栅极氧化层极薄，静电（ESD）可直接击穿。人体 ESD 可达 4~8 kV，即使经过皮肤衰减也会损坏器件。

输入保护典型方案：51 kΩ + TVS
51 kΩ 串联电阻 ：限制 ESD 冲击电流（8kV / 51kΩ ≈ 157 mA，低于 TVS 泄放能力）；自身热噪声 = √(4kTRΔf) = √(4×1.38×10-23×310×51000×100) ≈ 0.9 μVpp @100Hz 带宽，可接受
TVS 二极管 ：钳位电压 5.6V，双向，吸收 ESD 能量（注意选低电容型 < 2pF，避免高频信号衰减）
51kΩ 的副作用 ：与输入电容形成 RC 低通。输入电容 ≈ 10pF 时，f_-3dB = 1/(2π×51000×10×10-12) ≈ 312 kHz，远高于 EEG 带宽，无影响

4.2 OPA333 不是 EEG 首级优选的定量验证

需要更新的认知

OPA333 本身是零漂器件，不能再按“普通 CMOS、1/f 很严重”去理解。它不适合 EEG 首级的主要原因是：白噪声密度偏高、带宽有限、综合噪声不够低，而不是因为它没有零漂技术。

Vn_rms ≈ √( Vwhite2 + VLF2 )
白噪声项 ：55 nV/√Hz × √(100Hz) ≈ 0.55 μVrms
低频噪声项 ：0.01~10Hz 噪声 1.1 μVpp ≈ 0.17 μVrms
合成后 ：√(0.552 + 0.172) ≈ 0.58 μVrms
折算峰峰值 ：0.58 × 6.6 ≈ 3.8 μVpp
结论 ：这个量级已经接近弱 EEG 分量本身，因此 OPA333 更适合慢速精密测量，不适合作为 EEG 首级主放
纠正：问题不在“OPA333 没有零漂”
真正需要更新的是判断依据。OPA333 是零漂器件，但其综合输入噪声和带宽定位并不适合作为 EEG 首级。工程上应看 目标带宽内的总输入噪声，而不是只按“CMOS/JFET”标签做判断。

SECTION 5

第五章 斩波放大器完整原理

5.1 1/f 噪声物理根源

1/f 噪声（粉红噪声）源于半导体中晶格缺陷和界面态对载流子的随机俘获与释放（Trapping/De-trapping）。每个陷阱有特定的时间常数，大量陷阱叠加形成 1/f 谱。

特征：噪声功率密度 ∝ 1/f，频率越低噪声越强。对 CMOS 工艺尤为严重（MOS 栅氧化层界面态密度高）。

硬件工程师直观理解：1/f 噪声 vs 白噪声

白噪声像雨声——每个频率的能量均匀。你无法从雨声中听出"趋势"，每次测量结果独立随机、不相关。

1/f 噪声像溪流的缓慢起伏——低频成分多，意味着前后测量之间存在相关性（长期漂移）。这对 DC/低频测量是灾难性的。

斩波技术的核心思路：把信号从"溪流"（低频）搬到"雨声"（高频 f_chop 附近）去放大，避开 1/f 噪声占主导的低频区。放大完成后再解调回基带，同时把 1/f 噪声"踢"到高频处滤除。

噪声功率密度频谱示意（对数坐标）

5.1b 1/f 噪声在带宽内的 RMS 值计算

为什么需要计算 RMS 值？

数据手册通常给出的是电压噪声密度谱（单位 nV/√Hz），它与频率相关。要评估 1/f 噪声对测量精度的实际影响，必须将其在目标带宽内积分，得到 RMS 电压值（单位 Vrms 或 μVrms）。

1/f 噪声的功率谱密度

1/f 噪声（粉红噪声）的电压噪声密度随频率升高呈 -10 dB/dec 下降：

Vn_1f(f) = Vnw × √(fc / f)

其中：

  • Vnw：1/f 噪声在 1 Hz 处的电压噪声密度（单位 nV/√Hz）
  • fc：1/f 转折频率（Hz），白噪声与 1/f 噪声功率谱密度的交点
  • f：目标频率（Hz）

RMS 值完整推导

在频段 [fL, fH] 上对噪声功率积分：

Vn_rms² = ∫fLfH Vn(f)² df
= Vnw² × fc × ∫fLfH (1/f) df
= Vnw² × fc × ln(fH / fL)

开方后得到 1/f 噪声的 RMS 电压公式：

Vn_rms_1f = Vnw × √(fc × ln(fH / fL))

若将 Vnw² × fc 整体视为 1/f 噪声的归一化功率密度常数 Kv：

Vn_rms_1f = √(Kv × ln(fH / fL))
关键洞察：ln(fH/fL) 是对数函数，意味着 RMS 噪声对带宽扩展不敏感，但对下限频率 fL极其敏感。fL 从 1 Hz 降到 0.1 Hz，ln(fH/fL) 增加约 2.3，RMS 噪声增大约 1.5 倍。这就是直流/低频测量中 1/f 噪声是致命威胁的根本原因。

5.2 斩波原理（物理层面）

① 调制：信号从低频搬到 f_chop 附近
输入斩波开关以 f_chop（如 200kHz）周期性翻转输入极性，信号频谱从基带 f_sig 搬移到 f_chop ± f_sig 处，逃离 1/f 噪声严重的低频区
② 放大：在高频段安全放大
主放大器对已调制的信号进行高增益放大。此时信号在 f_chop 附近，而放大器的 1/f 噪声仍在基带 DC~几百 Hz，二者频域分离，1/f 噪声不会被放大到信号上
③ 解调：信号恢复到基带
输出斩波开关（与输入同步）再次翻转，使信号恢复到基带。1/f 噪声此时被搬移到 f_chop 处（脱离基带）
④ 低通滤波：滤除搬移到高频的噪声
LPF 截止频率设为信号带宽（如 200 Hz），远低于 f_chop。1/f 噪声（已在 f_chop 处）被滤除，输出为干净放大的信号

5.2.1 斩波运放内部架构（以 ADA4522 为例）

内部信号路径：输入 → 斩波调制 → Gm 放大 → 解调 → LPF → 输出；phi1/phi2 由内部振荡器固定 50% 占空比产生

5.2.2 外部斩波前端硬件框架

只讲“斩波原理”还不够，立项时更关键的是它如何落到板级架构。在 EEG 里，斩波运放通常不是孤立存在，而是作为高输入阻抗、低漂移的首级缓冲或前置增益块，后面再接仪表放大/ADS1299、RLD 和数字处理。

系统级建议：电极 → ESD/限流 → EMI RC → 斩波缓冲/前置增益 → ADS1299 或 INA+ADC；RLD 负责压低人体共模
模块推荐做法为什么要这样放
电极接口每通道先做串联限流和低电容 ESD先保护，再谈低噪声；否则前级 MOS 输入很脆弱
EMI RC小电阻 + C0G/NP0 小电容，截止做在几十 kHz 量级抑制射频和线缆耦合，不把 RC 截止压到 EEG 通带里
斩波前级干电极优先 OPA388，湿电极/噪声优先 ADA4522干电极首先怕偏置电流乘以接触阻抗；湿电极更看重电压噪声
后级采样优先 ADS1299 这类集成 AFE；特殊需求再拆成 INA + ADC多通道同步、RLD、导联脱落检测和软件生态更完整
共模控制RLD/BIAS 单独规划稳定性与患者安全电阻很多 EEG 项目最后不是败在 ADC，而是败在工频共模处理
工程落地建议：如果目标是 8 通道以内、湿电极、尽快出样机，优先从 ADS1299 直连或“ADS1299 + 轻量 RC”开始；如果目标是 干电极、长导联、可穿戴运动场景，再评估“电极端缓冲”或“主动电极”架构。

5.3 数学推导（完整版）

数学推导总览

以下 5 步展示信号和噪声在斩波放大器各阶段的演变。核心思想：ch(t) 取值 ±1，ch2(t) ≡ 1，使信号完美恢复；同时 1/f 噪声被搬移到高频滤除。

STEP 1/5 调制 — 信号搬移到高频
Vch(t) = Vin(t) × ch(t)
Vin(t)输入信号，幅度 μV 级，频率 fsig（如 EEG α 波 10 Hz）
ch(t)斩波函数，取值 +1 或 -1，频率 fchop（固定 50% 占空比）
Vch(t)调制后信号，频谱从 fsig 搬移到 fchop ± fsig 处
STEP 2/5 ch(t) 的傅里叶展开 — 方波由基波和奇次谐波构成
ch(t) = (4/π) · [ sin(ωchop·t) + (1/3) sin(3ωchop·t) + (1/5) sin(5ωchop·t) + … ]
4/π方波基波幅度系数 ≈ 1.27（调制造成的幅度变化在解调时恢复）
谐波奇次谐波 (3f, 5f, …) 幅度以 1/n 递减，信号同时出现在这些频率上
STEP 3/5 放大 — 信号在 fchop 被放大，噪声在基带被放大
Vampl(t) = A · Vch(t) + n1/f(t) + nwhite(t)
A放大器增益（如 100 倍）
n1/f(t)放大器 1/f 噪声，集中在 DC ~ 几百 Hz（基带），仍在低频区
nwhite(t)热噪声（白噪声），全频段均匀分布，斩波无法消除
STEP 4/5 解调 — 信号恢复基带，1/f 被搬移到高频
Vdemod(t) = Vampl(t) × ch(t)
           = A · Vin(t) · ch2(t) + n1/f(t) · ch(t) + nwhite(t) · ch(t)
ch2(t) ≡ 1关键！ ch(t) 只取 ±1，平方恒为 1 → 信号项 = A · Vin(t)，完美恢复
n1/f · ch1/f 噪声被搬移到 fchop 附近（离开基带），LPF 可滤除
nwhite · ch白噪声调制后折叠回基带，等效噪声密度 × √2（+3dB 代价，不可避免）
STEP 5/5 低通滤波 — 滤除噪声，输出纯净放大信号
Vout(t) = LPF{ Vdemod(t) } ≈ A · Vin(t)
LPF 截止设为 信号带宽（如 200~500 Hz），不是 fchop/2
被滤除fchop 处的 1/f 噪声残余、斩波开关 glitch（纹波）
保留A · Vin(t)（纯净放大信号）+ √2 × 白噪声（+3dB，不可消除）
核心结论：斩波技术用 +3dB 白噪声代价换取 1/f 噪声的完全消除。EEG 频段（0.5~100 Hz）内 1/f 噪声通常比白噪声高 10~100 倍，这笔账非常划算。
常见错误纠正
① LPF 截止频率不是 f_chop/2，应为信号带宽（< ② "放大器噪声在高频段很低"不准确：应为"放大器的 1/f 噪声在 f_chop 处很低"；白噪声在 f_chop 处依然存在
③ 斩波不是 PWM：固定 50% 占空比，由内部振荡器产生，不依赖外部参考

5.4 phi1/phi2 非交叠时钟

非交叠的目的

phi1 和 phi2 之间存在 5~20 ns 的死区（两路同时为低）。防止 phi1 未完全断开时 phi2 已导通，造成 Vin+ 与 Vin- 短路（低阻路径会产生大电流并损坏器件）。

开关切换时序

phi1 高电平：Vin+ → 放大器正端，Vin- → 负端（正接）

phi2 高电平：Vin+ → 放大器负端，Vin- → 正端（反接）

死区期间：所有开关断开，ch(t) = 0（短暂的高阻状态）

斩波 ≠ PWM（重要区别，专门澄清）
PWM（脉冲宽度调制）：脉冲宽度由外部参考量（如误差电压）控制，占空比可变，用于功率调节或 DAC。
斩波时钟：由芯片内部振荡器产生，占空比严格固定为 50%，频率固定（ADA4522 约 200 kHz），不依赖任何外部信号。
本质区别：斩波是频率搬移工具（乘法器），PWM 是幅度/能量调制工具。

5.5 噪声折叠（Noise Folding）详细分析

为什么白噪声增加 √2 倍？不是因为混叠！

不是混叠（Aliasing）。混叠是采样频率不足导致高频信号"冒充"低频。噪声折叠是斩波解调本身的频谱搬移：方波解调器 ch(t) 的频谱在 f_chop, 3f_chop, 5f_chop... 都有分量，每一处的白噪声都会被搬回基带叠加。

噪声折叠机制（直观理解）
类比 ：两面镜子相对放，一束光变成两束——斩波解调把 f_chop 两侧边带的噪声都"反射"回基带
功率视角 ：若载波两侧边带的白噪声功率谱密度都近似为 S0，则解调回基带后 S_baseband ≈ S_left + S_right ≈ 2S0
电压视角 ：功率翻倍对应电压噪声密度增加为 √2 ×，即约 +3 dB
为什么更直观 ：这里最关键的不是谐波级数，而是“左、右两份独立白噪声都被搬回同一基带”
工程结论 ：白噪声增加约 √2 倍是斩波技术的典型代价；具体数值还会受器件内部拓扑、纹波抑制和后级带宽影响，而数据手册给出的输入噪声通常已经包含这些现实因素
噪声折叠示意图：f_chop 两侧边带噪声经解调后都回到基带叠加 → 能量翻倍
注意：噪声折叠是斩波技术的固有代价，但这是可预知、可量化的代价。EEG 频段内 1/f 噪声通常比白噪声高 10~100 倍，用 +3dB 白噪声代价换取 1/f 的完全消除，这笔账非常划算。

5.6 斩波纹波（Glitch）与 Ripple Rejection

纹波的产生机制

解调开关每次切换时，MOS 管栅极寄生电容（C_gate ≈ 0.1~1 pF）上的电荷通过信号路径放电，产生电荷注入（Charge Injection）。这些冲击脉冲以 f_chop 为基频出现在输出端，幅度可达几十 μV 至几百 μV（未补偿前）。

厂商技术效果

ADI（ADA4522）Ripple Rejection Loop（反馈相消）Vos < ±2.5 μV（含纹波）
ADI（LTC2057）时钟抖动 + 后级滤波残余纹波 1.5 μVpp

SECTION 6

第六章 滤波器设计

6.1 Σ-Δ ADC 与抗混叠滤波的真实关系

更新后的更准确说法：Σ-Δ ADC（如 ADS1299）显著减轻了传统陡峭模拟抗混叠滤波器的压力，但这并不等于“外部模拟滤波完全不需要”。板级 RC 仍然推荐用于 EMI、强带外干扰、输入稳定性和斩波残余带宽控制。

Σ-Δ ADC 内部已做的

  • 过采样：f_s >> 奈奎斯特频率（ADS1299 调制器在 MHz 级运行）
  • 内部数字 sinc 滤波器：在 f_s/2 处衰减 > 100 dB
  • 抽取（Decimation）：降低数据率到设定采样率

外部 RC 真正的目的

  • EMI 防护：滤除射频干扰（手机信号、WiFi 等 GHz 频率）
  • 带外大信号抑制：避免强 RF、开关电源噪声和除颤/ESD 恢复过程把前端压进非线性区
  • 噪声带宽限制：减少前级运放和斩波残余进入 ADC 的宽带噪声
  • 更准确的说法：不是“完全不做模拟滤波”，而是“不再需要传统高阶陡峭抗混叠滤波器”

6.2 sinc 滤波器特性

sinc3 滤波器频率响应
|H(f)| = |sin(πf/f_s) / (πf/f_s)|3
f_s ：调制器采样频率（远高于输出数据率）
特点 ：在 f = f_s（和整数倍）处有精确零点，对带外频率有很强抑制；但通带边缘会下垂，群延迟也不可忽略
工程提示 ：具体到 ADS1299，应以数据率设置、50/60Hz 抑制需求、群延迟和实测频响为准，不要只背一个“固定 -3dB 截止点”
sinc3 vs sinc4 滤波器幅频响应（归一化频率，0dB = 通带）

6.3 外部 RC 设计要点

参数典型值注意事项
截止频率10~100 kHz高于信号带宽，低于调制器频率；目的是 EMI 而非抗混叠
电阻值1~10 kΩ太大会与输入电容形成额外热噪声；金属膜电阻优先
电容类型C0G/NP0无压电效应，温度系数稳定；避免 X7R/X5R（见 Section 7）
电容值100 pF ~ 1 nF保持小值避免与运放输出阻抗形成不稳定
高通滤波器的漏电流风险：串联大电容的高通设计（如信号耦合用的 μF 电容）会引入 RC 时间常数极长的直流路径，电容漏电流会产生慢漂移误差电压。应在 ADS1299 内部数字域实现直流去除（配置 HPF 寄存器），而非外部模拟高通。
SECTION 7

第七章 电容选型：DC偏压效应与压电噪声

7.1 MLCC DC 偏压效应

X7R/X5R 介质的 MLCC 在 DC 偏压下电容量显著下降（有时高达 80%）。这会使滤波器截止频率偏移，甚至导致增益误差。

DC 偏压效应量化
典型 X5R 10μF 0402 在 5V 直流偏压下实际电容量可能只剩 2~3 μF（降额 70~80%）
工程原则 ：选用额定电压 ≥ 2× 工作电压，例如工作在 3.3V 时选 10V 或 16V 额定的电容
验证方法 ：在器件选型前查阅厂商 DC Bias 特性曲线（如 Murata SimSurfing 工具）
电容材质最大容量DC 偏压降额压电噪声适用场景
C0G / NP0≤ 0.1 μF几乎无几乎无精密模拟滤波、基准去耦
X7R几十 μF中等（20~60%）中等通用去耦，非精密
X5R100 μF较大（60~80%）较大电源去耦，可接受降额
电解电容（钽/铝）毫法级小无大容量滤波，但 ESR 高、有漏电流
传统观点需要更新
传统"大电容滤低频、小电容滤高频"的选型原则基于当时电容工艺。现代 MLCC 已可达 100μF，且谐振频率远高于传统电解电容。关键约束已从容量变为：DC 偏压降额效应（X5R/X7R）和压电噪声（见下节）。
MLCC DC 偏压降额效应：不同材质在 5V 偏压下实际电容量 vs 标称值

7.2 压电噪声（Piezoelectric Noise）

MLCC 压电效应的 EEG 影响

X5R/X7R 材质（BaTiO3 基）是铁电材料，具有显著的压电效应。机械振动（可穿戴设备中普遍存在）转换为电荷信号叠加到电路中。

压电噪声量化估算
典型值 ：10μF X5R MLCC 在 1g 振动下可产生 1~10 μVpp 噪声
频段 ：人体运动频率 0.5~20 Hz，恰好与 EEG δ、θ、α 波重叠
结论 ：精密模拟通路（输入滤波、基准去耦）必须使用 C0G/NP0；电源去耦可用 X5R，但需与 C0G 并联（C0G 保证高频特性）

7.3 漏电流评估

漏电流等效模型：I_leak = V / (IR × C)
IR ：绝缘电阻（Insulation Resistance），单位 Ω·F，通常规格为 IR ≥ 1000 MΩ·μF（即 IR×C ≥ 1000 MΩ·μF）
C ：电容量（F）
V ：工作电压（V）
示例 ：C=1μF，V=5V，IR=1000MΩ·μF → I_leak = 5V / (1000MΩ) = 5 nA（现代 MLCC 漏电流极低）
对比 ：铝电解电容漏电流 = 0.01×C(μF)×V(V) μA，100μF×5V = 5μA，比 MLCC 高 1000 倍

第八章 系统级评估指标

8.1 SINAD vs SNR

关键纠正：仅考虑运放噪声密度是不够的
SNR（信噪比）只考虑热噪声，而 SINAD（Signal to Noise and Distortion Ratio，信纳比）还包含谐波失真（THD）、互调失真（IMD）和其他干扰。评估 ADC/AFE 动态性能时要看 SINAD，而评估 EEG 微弱信号时还要同时看输入参考噪声、CMRR 和运动伪迹。
SINAD = Signal / (Noise + Distortion + Interference)
Noise ：热噪声（1/f + 白噪声）
Distortion ：谐波失真（THD）：大信号下运放非线性产生的 2f、3f 谐波；互调失真（IMD）：两个频率相互调制
Interference ：电源纹波通过 PSRR 耦合；时钟串扰（f_chop 耦合）；共模噪声残余（CMRR 有限）
实际 ADS1299 ：规格书 SINAD ≈ 103 dB（250 SPS），考虑了全部失真
干扰来源量级估算抑制手段
运放热噪声（白噪声）0.1~1 μVpp斩波技术（消 1/f）+ 低噪声运放选型
电源纹波（通过 PSRR）0.1~10 μVppLDO 电源 + 100nF C0G 去耦
50Hz 工频共模（通过 CMRR 残余）~1 μVpp提高 CMRR + RLD 电路驱动参考
斩波时钟串扰0.01~0.1 μVppPCB 输入走线远离时钟层
压电噪声（运动伪迹）1~10 μVpp信号通路使用 C0G 电容

8.2 噪声预算（Noise Budget）

总等效输入噪声（RSS 合并）
V_total_rms = √(V_amp2 + V_adc2 + V_psu2 + V_emi2)
典型值（湿极 + ADS1299，250SPS） ：
　V_amp（ADS1299 内部）= 1 μVpp ≈ 0.15 μVrms
　V_electrode = 0.5 μVrms（Ag/AgCl 接触噪声）
　V_psu = 0.2 μVrms（LDO 电源）
　V_total ≈ √(0.152 + 0.52 + 0.22) ≈ 0.56 μVrms ≈ 3.7 μVpp
EEG 可检测信号：delta 波（0.5~4Hz）50~200 μVpp，SNR > 40 dB；alpha 波（8~13Hz）10~50 μVpp，SNR > 20 dB；单个神经元锋电位（需皮层内电极）< 1 μVpp，SNR 紧张。
噪声预算 RSS 合成：各噪声源对总输入噪声的贡献占比

9.2 ADS1299 软件驱动逻辑

Step 1：上电复位
PWDN 拉高 → 等待 218 CLK（约 18ms @4MHz）→ 发送 RESET 命令 → 等待 18 CLK → 发送 SDATAC（停止连续读）
Step 2：写配置寄存器
CONFIG1(0x96)：采样率 250SPS；CONFIG3(0xEC)：内部基准 4.5V + 偏置缓冲；CH1SET(0x60)：增益×24，正常输入
Step 3：START → RDATAC
START 命令启动转换；RDATAC 进入连续读取模式（每次 DRDY 后自动输出数据，无需重发 RDATA）
Step 4：DRDY 中断读取
DRDY 下降沿触发外部中断（非轮询），在 ISR 中读取 27 字节：3字节状态 + 3字节×8通道
Step 5：数据解析与换算
raw = (buf[3]<<16)|(buf[4]<<8)|buf[5]；符号扩展（24-bit → 32-bit）；V_uV = raw / 8388608.0 × (VREF_uV / PGA_gain)
ADS1299 软件状态机：初始化与数据流状态转换
/* ADS1299 SPI 寄存器初始化 */ void ads1299_init() { spi_cmd(0x06); // RESET delay_ms(1); spi_cmd(0x11); // SDATAC reg_write(CONFIG1, 0x96); // 250 SPS, 内部时钟 reg_write(CONFIG2, 0xC0); // 关闭内部测试信号 reg_write(CONFIG3, 0xEC); // 内部基准 4.5V + 偏置缓冲 for(int ch=0; ch<8; ch++) reg_write(CH1SET+ch, 0x60); // 增益×24，差分输入 reg_write(BIAS_SENSP, 0xFF); // 所有通道参与 RLD spi_cmd(0x08); // START spi_cmd(0x10); // RDATAC } /* DRDY 中断服务例程 */ void DRDY_ISR() { uint8_t buf[27]; spi_read(buf, 27); for(int ch=0; ch<8; ch++) { int32_t raw = (buf[3+ch*3]<<16)|(buf[4+ch*3]<<8)|buf[5+ch*3]; if(raw & 0x800000) raw |= 0xFF000000; // 24-bit 符号扩展 // VREF=4500000μV, PGA=24 float uV = (float)raw / 8388608.0f * (4500000.0f / 24); eeg_buffer[ch] = uV; } }
ADA4522-1 无需软件配置：纯模拟器件，无寄存器，无 I2C/SPI 接口。上电即工作，斩波频率由内部振荡器固定（约 200kHz）。工程师的任务仅限于正确的硬件电路设计。

9.3 立项前你还应该确认什么

先回答这 6 个问题，再决定走哪条技术路线

问题如果答案偏左更倾向的路线
电极类型？湿电极、阻抗可控ADS1299 集成方案优先
是否可穿戴/运动场景？是，且导联会晃动前级缓冲、主动电极、机械固定设计一起考虑
通道数和同步要求？≥16ch，且事件同步严格多颗 AFE 同步、时钟树和数据链路要先规划
功耗预算？纽扣电池/长续航优先集成 AFE，避免每通道都上高功耗分立链路
是否要过医疗/人体安全评估？是隔离、电极限流、漏电流、ESD 和 EMC 不能后补
最终算法目标？只看 α/β 节律 vs 还要 ERP/睡眠/伪迹抑制算法目标会反推硬件带宽、群延迟、导联质量和参考方式

推荐的 MVP 路线

  • 湿电极 + 8ch：先做 ADS1299 + RLD + 良好 PCB/屏蔽
  • 先拿到稳定脑电，再决定是否增加外部缓冲
  • 优先把时间花在电极接触、工频抑制、导联线和结构件上
  • 第一版不要过早追求“极限 24-bit”，先追求可重复采集

常被低估的项目风险

  • 运动伪迹通常比芯片本底噪声大一个数量级
  • 干电极的痛点经常是接触稳定性，不只是运放噪声
  • RLD 失稳会让系统看起来像“ADC 很差”
  • EMC、ESD、患者漏电流在后期整改代价极高

建议你在立项前做的 4 个最小验证

① 空载噪声验证
短接输入、电极仿真阻抗、RLD 开关三种状态都测一次，区分芯片噪声与系统噪声
② 工频与共模验证
在真实线缆长度和真实电源环境下测 50/60Hz 残余，别只看实验室短线结果
③ 电极阻抗漂移验证
特别是干电极，至少要看佩戴 10~30 分钟后的漂移和接触波动
④ 算法端联调
尽早让算法同事看原始波形、PSD、导联脱落和伪迹标注，避免硬件指标与算法需求脱节
