滤波电路与数字信号处理

模拟滤波（无源/有源）与数字滤波（IIR/FIR/卡尔曼/匹配/中值）完整知识体系

第一章

滤波电路概述

1.1 滤波的作用

  • 从信号中滤除不需要的频率分量，保留有用信号。
  • 改善信号质量：去除噪声、干扰、毛刺。
  • 在数字系统中，可通过ADC采样后数字滤波实现类似效果，但模拟滤波仍然是信号调理的关键环节。

1.2 滤波器的分类（按频率特性）

类型特性典型应用
低通 (LPF)低频通过，高频衰减抗混叠滤波、电源去耦
高通 (HPF)高频通过，低频衰减去除直流偏置、交流耦合
带通 (BPF)只通过某一频段无线通信信道选择、超声信号提取（如40kHz）
带阻 (BSF)抑制某一频段陷波器（抑制工频干扰）
全通 (APF)幅值不变，仅改变相位相位均衡、延时调整

1.3 按器件分类

  • 无源滤波器：仅由 R、L、C 组成。无需供电，但增益≤0 dB，带载能力弱。
  • 有源滤波器：包含运放等有源器件。可提供增益，输入阻抗高、输出阻抗低，易于级联。
第二章

基本概念与术语

2.1 传递函数与阶数

  • 滤波器的传递函数 $ H(s) = V_{out}(s)/V_{in}(s) $ 是一个有理分式。
  • 阶数 = 分母多项式的最高次数。阶数越高，幅频特性过渡带越陡峭。
  • 一阶 RC 低通：$ H(s) = \frac{1}{1+sRC} $，斜率 -20 dB/dec。
  • 二阶滤波器：分母包含 $ s^2 $ 项，斜率 -40 dB/dec。
  • n 阶滤波器：理论衰减斜率 -20n dB/dec。

2.2 关键参数

参数定义说明
截止频率 $ f_c $增益下降 3 dB 处的频率常称为 -3dB 频率
通带允许信号通过的频率范围增益平坦度常用纹波（dB）表示
阻带信号被衰减的频率范围指定最小衰减量（如 -40 dB）
纹波 (Ripple)通带内增益的波动幅度切比雪夫滤波器有通带纹波
品质因数 $ Q $$ Q = f_0 / BW $（对于带通）描述滤波器选择性，Q 越高，带宽越窄
中心频率 $ f_0 $带通/带阻滤波器的几何中心频率

2.3 极点、零点与斜率关系

  • 极点：分母=0 的频率，使增益下降。
  • 零点：分子=0 的频率，使增益上升或陷波。
  • 每个极点贡献 -20 dB/dec 的最终衰减斜率，每个零点贡献 +20 dB/dec。
第三章

常见幅频响应类型（以低通为例）

类型通带平坦度过渡带陡峭度相位特性典型应用
巴特沃斯最平坦（无纹波）适中相位非线性，群延迟较差通用滤波，要求幅值保真
切比雪夫有纹波（可控制）最陡峭（相同阶数）相位更差要求快速衰减，允许通带波动
贝塞尔较平坦最缓慢线性相位（群延迟恒定）波形保真（方波、脉冲），无过冲

工程选择原则：输入信号为单一正弦波时可用切比雪夫；要求波形不失真（如方波、脉冲）时用贝塞尔；折中用巴特沃斯。

第四章

常用二阶有源滤波器拓扑结构

4.1 多路反馈滤波器 (MFB, Multiple Feedback)

特点：

  • 运放接成反相放大形式。
  • 元件值变化对滤波器性能敏感度低（鲁棒性好）。
  • 输出与输入反相（额外的 180° 相移）。
  • 适合低失真、中等 Q 值应用。

低通 MFB 典型电路：输入电阻 R1，反馈电阻 R4，接地电容 C1，反馈电容 C5，以及运放反相端到地的电阻 R3。

高通/带通 MFB：将低通电路中的 R 和 C 位置互换即可获得高通；带通则需更复杂的网络。

4.2 Sallen-Key 滤波器

特点：

  • 运放接成同相放大（或单位增益）。
  • 对元件敏感度较高，但设计简单，可提供增益。
  • 输入输出同相。

优缺点对比：

特性MFBSallen-Key
增益反相，可任意设定同相，最小为单位增益
元件敏感度低较高
高频性能较好（运放带宽利用率高）受运放共模限制
设计复杂度稍高简单
第五章

品质因数 Q 的深入理解

  • 对于二阶低通/高通，Q 决定幅频响应在截止频率附近的峰值。
  • Q = 0.707（巴特沃斯）：响应最平坦。
  • Q > 0.707：出现峰值（可能引起过冲）。
  • Q < 0.707：响应缓慢下降。
  • 对于带通滤波器：$ Q = f_0 / BW $，其中 BW 为 -3dB 带宽。Q 越高，选择性越好，但实现难度增加，且对元件误差敏感。
  • 工程上，有源滤波器单级 Q 通常 ≤ 10，更高 Q 需要使用多级级联或更高阶数。
第六章

滤波器设计方法（工程实用）

6.1 传统手工设计（了解即可）

  • 根据响应类型查表得到归一化低通原型参数。
  • 通过频率变换（低通→高通/带通）和阻抗缩放计算实际 R、C 值。
  • 缺点：计算繁琐，容易出错。

6.2 使用专用设计软件（推荐）

  • TI FilterPro、ADI Filter Design Wizard、Nuhertz Filter Solutions 等。
  • 设计步骤：

1. 选择滤波器类型（低通/高通/带通/带阻）。

2. 设置通带截止频率、阻带频率、通带纹波、阻带衰减等指标。

3. 选择响应类型（巴特沃斯/切比雪夫/贝塞尔）。

4. 选择拓扑结构（MFB / Sallen-Key）。

5. 软件自动计算阶数，给出电路图及标准元件值。

6. 仿真验证幅频/相频响应。

6.3 设计注意事项

  • 指标过严会导致软件提示“阶数无法实现”，需放宽（例如增大过渡带宽度）。
  • 实际电阻、电容应选用 1% 精度，电容建议选用 C0G/NPO 材质。
  • 运放带宽至少为 $ 100 \times f_c $。
第七章

实例分析：从方波提取正弦波

7.1 方波的频谱

  • 方波由基波和奇次谐波组成：$ f, 3f, 5f, \dots $。
  • 若基波频率为 1 kHz，则包含 1 kHz、3 kHz、5 kHz 等成分。

7.2 带通滤波器提取基波（1 kHz）

  • 设计中心频率 $ f_0 = 1\ \text{kHz} $，带宽尽量窄（如 50 Hz），高 Q 值。
  • 输入方波 → 带通滤波器输出 → 得到 1 kHz 正弦波（基波）。

7.3 提取三次谐波（3 kHz）

  • 设计另一个带通滤波器，$ f_0 = 3\ \text{kHz} $，同样窄带。
  • 输入方波 → 第二个带通 → 输出 3 kHz 正弦波。

7.4 多级滤波改善波形质量

  • 单级带通滤波器输出波形可能存在幅度波动（因Q不够高或过渡带不平滑）。
  • 级联两级相同中心频率的带通滤波器（总阶数增加），可进一步抑制旁瓣，输出更纯净的正弦波。
第八章

全通滤波器（移相器）

  • 传递函数分子分母互为共轭，幅值恒为 1（0 dB）。
  • 相位随频率变化：可用于相位补偿、延迟均衡（使群延迟恒定）。
  • 典型应用：让信号通过全通网络后，与原始信号叠加，产生特定相位差（如 90°）。
第九章

滤波器设计中的工程陷阱

9.1 运放的有限带宽与压摆率

  • 运放的实际增益带宽积（GBW）必须远大于滤波器截止频率（通常 > 100×f\_c）。
  • 若运放带宽不足，会在高频引入额外相移，改变滤波器响应（可能引起自激）。

9.2 寄生电容与电感的影响

  • 高频时，电阻的寄生电容、PCB 走线电容会改变滤波器特性。
  • 建议：电阻选用贴片薄膜电阻；运放反馈电阻尽量小（几百Ω\~几kΩ）；电容使用 C0G。

9.3 元件精度与温度漂移

  • 滤波器对 R、C 的绝对值敏感，1% 电阻 + 5% 电容可能导致截止频率偏差 ±5% 以上。
  • 高 Q 滤波器对元件匹配要求更高，建议使用 1% 电容或通过微调（并联电容）调整。

第十一章

数字滤波器基础：IIR 与 FIR

11.1 IIR 滤波器 (Infinite Impulse Response)

核心原理：

  • 有“反馈环路”，当前输出不仅取决于当前输入和过去输入，还取决于过去输出。
  • 属于递归滤波器，冲激响应理论上是无限长的。

特点：

  • 优点：阶数低，计算量小；性能高（陡峭的过渡带）。
  • 缺点：无线性相位（信号易相位失真）；存在稳定性风险。
  • 设计方法：可仿照模拟滤波器（巴特沃斯/切比雪夫），经双线性变换将s域传递函数映射到离散z域。

工程选型：适合资源紧张的嵌入式设备，如脑电采集中用Butterworth IIR高效滤除高频噪声。

11.2 FIR 滤波器 (Finite Impulse Response)

核心原理：

  • 无“反馈”环节，只由当前输入和有限的过去输入加权累加得出输出。
  • 实现即卷积运算，冲激响应有限长。抽头数决定阶数和性能。

特点：

  • 优点：设计任意幅频特性时能保证严格的线性相位（波形保真）；绝对稳定。
  • 缺点：计算量大，对算力要求较高；实现同样幅频特性时阶数通常比IIR高。

工程选型：适合精确信号分析。ERP分析中，为确保波形峰值位置不变，首选FIR滤波器。

11.3 IIR vs FIR 快速决策表

决策维度IIR滤波器FIR滤波器
绝对算力要求较低较高
嵌入式实时性非常适合适合（资源充裕时）

第十二章

进阶数字算法：卡尔曼滤波、匹配滤波、中值滤波

12.1 卡尔曼滤波 (Kalman Filter)

核心原理：

  • 递推算法，利用线性系统状态方程，通过观测数据对系统状态进行最优估计。
  • 过程是“两步走”循环：预测（基于上一状态估计）→ 更新（根据测量值修正）。

核心优势：

  • 有效滤除高斯噪声，擅长融合多个带噪的传感器数据。
  • 内存占用极小，只依赖上一状态及协方差矩阵，极适合嵌入式。

经典应用：

  • 四轴飞行器姿态解算（融合陀螺仪+加速度计）。
  • GPS/IMU组合导航（平滑GPS信号并填补更新间隙）。

12.2 匹配滤波 (Matched Filter)

核心理念：

  • 让滤波器与输入信号本身相匹配。其冲激响应是输入信号的时间镜像反转，本质上是相关运算。

工作原理：

  • 发射特定编码的探测脉冲（线性调频/相位编码），接收端用匹配滤波处理回波。
  • 实现“脉冲压缩”：将宽脉冲能量“压缩”成高分辨率窄脉冲，同时最大化输出信噪比。

经典应用：

  • 雷达、声纳系统，兼顾“看得远”（发射宽脉冲）与“看得清”（得到窄脉冲）。

12.3 中值滤波

功能定位：

  • 针对脉冲噪声（椒盐噪声） 的“特效药”，常用于图像预处理阶段。
  • 非线性算法：对滤波窗口内所有数据点进行排序，取中间值作为输出。

工程优势：

  • 在破坏和清除孤立噪声点的同时，最完美地保护信号的边缘和细节。
  • 对于ECG（心电图）采集，中值滤波可在消除高频肌电噪声的同时，完整保留尖峰QRS波群。
第十三章

数字滤波器设计决策指南（决策树）

  • 是否必须实时且模拟信号直接输入？ 是 → 选用模拟滤波前端
  • 是否追求工程稳定性、且能承担计算量？ 是 → 选用FIR 滤波
  • 是否资源极度受限、且不关心相位失真？ 是 → 选用IIR 滤波
  • 是否需同时处理动态系统预测与多传感器融合？ 是 → 选用卡尔曼滤波
  • 是否主要应对孤立的“尖刺”或“椒盐”噪声？ 是 → 选用中值滤波
  • 是否严格追求雷达/声纳探测的最优信噪比？ 是 → 选用匹配滤波

第十五章

总结

本笔记系统覆盖了从模拟滤波到数字滤波的完整知识体系：

1\. 模拟部分：掌握了滤波器的分类、关键参数、响应类型（巴特沃斯/切比雪夫/贝塞尔）、拓扑结构（MFB/Sallen-Key）、品质因数Q、设计方法（软件工具）以及工程陷阱。

2\. 数字部分：理解了IIR与FIR的区别与选型、卡尔曼滤波的最优估计原理、匹配滤波的信噪比最大化特性、中值滤波的脉冲噪声抑制能力。

3\. 整合视角：模拟滤波处理物理前端，数字滤波实现灵活算法，二者互补构成现代信号处理链路的基础。
