纳伏表竞品调研与技术方案报告

对标 Keithley 2182A · 竞品调研 + 技术选型 + 方案建议 · 2026-05-25

一、执行摘要

核心结论：在公开可查渠道中，目前未发现国产量产纳伏专用仪器。方瞳科技 FT3570 是七位半万用表（8nVpp 噪声），并非专用纳伏表。尚无产品能直接对标 Keithley 2182A 的 15nVpp@1s 水平。重要发现：老款 Keithley 2182（非 A 版）在特定测试条件下（源电阻 1kΩ、模拟滤波开启、数字滤波 100）的噪声指标为 70 nV p‑p（Keithley 2182 Service Manual Page 93），这可能是您提到的"国内有一家做到了70nV"的参考基准。建议以"先达 70nVpp → 再追 15nVpp"分两阶段开发，技术路线采用分立 JFET 斩波调制前端 + Σ-Δ ADC + 低热电势全链路设计。

⚠️ 100pV ≠ nV 测量能力：

>

FT3570 标称的"100pV 灵敏度"是 7½ 位显示在 1mV 量程的末位数字分辨率（1 LSD），而非真实可分辨的噪声底限。实际有效噪声底限为 8nVpp，末位约 80 个计数被噪声淹没。这意味着：
- 能测到 nV 级信号（8nV 约为 2182A 15nV@1s 的一半），但无法达到 1nV 级有效测量
- 与 2182A 的本质区别：2182A 通过 Delta 模式多次平均可将有效噪声降为 ~1nV，FT3570 无 Delta 模式、无电流源硬件同步能力
- 未见与 6220/6221 类电流源的硬件同步能力，这两点是 2182A 的核心壁垒

2.5 关于"70nV 国产产品"的说明

在本次调研范围内的公开渠道中，未找到任何国产纳伏表产品明确标注 70nV 噪声水平。但 Keithley 2182 Service Manual（Page 93）明确列出了 70 nV p‑p 这一噪声值（测试条件：源电阻 1kΩ、模拟滤波开启、数字滤波 100）。

关键提醒：如果那家国产公司的"70nV"是基于与 Keithley 2182 相同的测试条件（1kΩ 源阻 + 强滤波），则需要警惕以下问题：

  • 源电阻贡献的 Johnson 噪声：1kΩ 电阻在室温下产生 ~4 nV/√Hz 热噪声，在窄带宽下可降到几十 nV，但对测量条件要求严苛
  • 与 2182A 的直接差距：2182A 在 0Ω 短路输入 下实现 15nVpp@1s，如果国产产品需要 1kΩ 源阻 + 强滤波才能达到 70nV，则实际噪声底限差距巨大

建议 Phase 0 要求供应商明确说明：70nV 的完整测试条件（源电阻、NPLC、滤波器配置、等效噪声带宽）。

3.2 核心技术决策点

决策 1：斩波频率选择

频率选择优点缺点适用场景
<100Hz（低频斩波）电荷注入小、开关噪声低1/f 噪声抑制不完全极限低噪声应用
~1kHz（中频斩波）综合性能好、远离工频需要处理开关瞬态推荐起点
>10kHz（高频斩波）1/f 噪声抑制彻底电荷注入大、EMI 问题高速应用

2182A 的斩波频率未公开（以下为基于公开技术分析的推测，非官方确认数据），基于其 60ms 响应时间推算，有效测量窗口约为几十 ms 量级，斩波频率可能在几百 Hz 范围。开源项目 curtisseizert 使用的是低频斩波（可通过关断自动归零实现），以降低电荷注入。

建议：第一版选择 ~500Hz-1kHz，避开 50/60Hz 工频及其谐波。

决策 2：JFET 选型 — 最关键的前端决策

纳伏表前端的电压噪声密度直接决定系统噪声底限。pA 计关注的是电流噪声（fA/√Hz），纳伏表关注的是电压噪声（nV/√Hz）。

器件电压噪声输入电容跨导匹配难度价格评价
IF3602 (InterFET)~0.3 nV/√Hz~300pF极高极大（参数离散性大）~$50理论上最优，但匹配极其困难
JFE2140 (TI)~1.5 nV/√Hz~75pF中内置匹配对~$8强烈推荐，专为差分设计
LSK389 (Linear Systems)~1.0 nV/√Hz~25pF中较好~$15经典方案，低电容优势
2SK209 (Toshiba)~1.5 nV/√Hz~15pF低需手动匹配~$1低成本选项，多片并联可降噪
BF862 (NXP, 已停产)~0.8 nV/√Hz~10pF高已停产—曾是优选，不可用于新产品

推荐：TI JFE2140。内置匹配对减少配对工作量，噪声参数可接受，供货稳定。

噪声并联降噪公式：N 个相同 JFET 并联，电压噪声降低 √N 倍，但输入电容增加 N 倍。开源项目 okokfun 用了 35 片 MCP6V51 并联达到 210nV 噪声（初始单片）/ √35 ≈ 35nV（等效推算），但这是用集成斩波运放的做法，不是最优路线。

决策 3：斩波调制拓扑选择

拓扑描述优点缺点
分立 JFET + 斩波调制解调输入信号经调制开关交替接入 JFET 差分放大器，输出经同步解调噪声最低、可与任意运放组合复杂度高、需要精确时钟、电荷注入
集成斩波放大器（如 ADA4528）使用厂商集成的斩波运放开发简单、失调极低噪声密度 >50 nV/√Hz，不适合纳伏表
交流耦合斩波 FET (ADI AN)LTC6241 + 分立 JFET + LTC179940nVpp，失调极低带宽受限、需 AC 耦合
35 片 MCP6V51 并联 (okokfun)多片集成斩波运放并联可工程实现功耗大、体积大、噪声收益边际递减

强烈推荐：分立 JFET + 斩波调制解调（curtisseizert 开源方案），已经被验证可以做到 <1.2 nV/√Hz。

⚠️ curtisseizert 方案的已知问题（来自项目作者公开描述）：
- 原型机存在 约 3nA 的偏置电流（源于输入调制开关的电荷注入），改进设计宣称可降至 <5pA，但尚未全面验证
- 使用的 PE4140 四 MOSFET 阵列 和 AD4030-24 ADC 均为非常规器件，需要专门采购渠道
- 电源设计采用 LT8608S buck + Cuk converter 组合，复杂度极高
- 建议 Phase 0 先用更简单的离散元件验证核心原理（如低电荷注入模拟开关 MAX4644 替代 PE4140），确认斩波调制解调架构的可行性后，再过渡到定制元件方案

核心原理（给从 pA 计转过来的工程师）：

pA 计思路：
输入电流 → TIA (反馈电阻 Rf) → 输出电压 = I_in × Rf
噪声源 = Rf 热噪声 + 运放输入电流噪声

纳伏表思路：
输入电压 → 斩波调制到 AC → JFET 放大（增益~3500）→ 同步解调回 DC → ADC
斩波的作用：将 DC/低频信号搬到斩波频率，绕过运放的 1/f 噪声
3500 倍增益后，后级运放的失调被衰减 3500 倍（等效~4nV/3500 = ~1pV）

3.3 低热电势设计（纳伏表最大的工程挑战）

这是 pA 计工程师最需要理解的新领域。

热电势根本问题

异种金属结 + 温度差 → 热电势（Seebeck 效应）
典型值：铜-氧化铜 = 1 mV/°C，铜-金 = 0.3 µV/°C

在 nV 级测量中，1 µV/°C 的结温差意味着 0.001°C 的温度差就能产生 1nV 误差。

全链路热结地图

输入端子 ──▶ 继电器触点 ──▶ PCB 焊点 ──▶ JFET 引脚
│              │               │
└─ Cu-Au结     └─ Cu-NiFe结    └─ Cu-SnPb结

低热设计的三个原则（实战可操作）

  1. 减少异种结数量：Force/Sense 路径中每减少一个金属过渡，就消除一个误差源
  2. 强制热对称：正负极性通道上的结数量和材料必须镜像，使热电势共模化从而互相抵消
  3. 隔热源：继电器线圈、基准源、电源芯片、MCU 等发热器件远离 Sense 节点

器件选型

类别推荐器件热电势备注
输入接线柱Low Thermal 2758 系列<0.1 µV碲铜 + 直接镀金（无镍底层）
输入电缆Keithley 2107-4 或 Pomona 低热系列—低热铜材 + 金铲形片
输入继电器Pickering 100/101 系列~1 µV（单刀）双刀差分切换时两开关热电势极性相反，可相互抵消得到更低有效热电势
PCB 焊料Sn63Pb37 或纯锡—保持焊接一致性
线缆纯铜线（非镀锡铜）—镀锡铜线与铜形成 Sn-Cu 结

热稳定时间

连接或切换后，不仅需要电气稳定，还需要热稳定。热电势是缓慢漂移（秒-分钟级），过早采样会把漂移"烤进"读数。经验法则：接线后等待至少 30 秒-2 分钟，视温差大小。

Delta 模式（消除残余热电势的终极手段）

Delta 模式原理：
+I 电流 → 测量 V1 = I×R + V_thermal
-I 电流 → 测量 V2 = -I×R + V_thermal
R = (V1 - V2) / (2I)

热电势 V_thermal 被数学消除（前提：它在 +/-I 之间保持恒定）

这是 2182A 与 6220/6221 电流源配合的核心功能，也是我们产品必须具备的能力。

七、竞品分层方法论（来自前期调研沉淀）

7.1 分层判定标准

第一梯队（真·纳伏表）：

  • 公开给出并可复现的"噪声-时间"指标（至少包含 1s/100ms 两点）
  • 输入结构明确面向低热电势/低漏电
  • 典型门槛：短路输入噪声 ≤20 nV p‑p @ 1s，或给出等价 nV/√Hz + 1/f 拐点
  • 支持 NPLC 同步积分（50/60 Hz 抑制）
  • 有系统级校准与不确定度口径（24h/90d/1y）

第二梯队（微伏表/高分辨率 DMM"接近纳伏用法"）：

  • 能做到 µV 级很强，但对 nV 测量依赖长时间平均/外接前置
  • 宣传"1 nV 分辨率/8.5 位显示"，但公开资料缺少完整噪声曲线或热电势/漏电约束

第三梯队（通用台表/数据采集）：

  • 不主打低热电势与 nV 噪声
  • 作为替代方案只能靠系统方案（放大+隔离+滤波+算法）

7.2 各梯队技术路线

梯队典型技术路线
第一梯队低热电势输入 + 继电器量程网络 + 斩波/自零前端 + 低噪声 ΔΣ ADC + NPLC 同步积分 + 数字滤波；极性翻转/Delta 协同测量抑制热电势与 1/f 漂移
第二梯队高分辨率 ADC 与数字平均为主，前端低噪声放大但未必满足纳伏级热电势控制；nV 场景需更长积分时间 + 更严格端子/线材/温差控制
第三梯队锁相放大器（AC 调制）把 DC 微弱信号调制到较高频段测量，避开 1/f；或前置低噪声放大器 + 高精度 DMM/DAQ 系统替代

12.5 Delta 模式精确算法（逆向工程核心公式）

时序：
2182A A/D:     A       B       C       D       E       F
622x 输出:    +I      -I      +I      -I      +I      -I

算法（三点移动平均）：
Delta_1 = (A - 2B + C) / 4 × (-1)^1
Delta_2 = (B - 2C + D) / 4 × (-1)^2
...

通式：Delta_n = (X - 2Y + Z) / 4 × (-1)^n

其中 (-1)^n 使所有 Delta 读数保持同极性

关键参数：I-High（0~+105mA）、I-Low（0~-105mA）、延迟（1ms~9999s，默认 2ms）、计数（1~65536 或无限）。2182A 反转速率最高 24Hz（老款 2182 为 12Hz）。Delta 模式下 NPLC 被强制为 1。

12.6 脉冲 Delta 模式（仅 6221 + 2182A）

适用于温度敏感器件。电流以脉冲形式输出，与电源线频率锁定同步。

参数范围默认值
脉冲宽度50μs ~ 12ms110μs
源延迟16μs ~ 11.966ms16μs
测量间隔（PLC）5 ~ 9999995
低测量次数1（两点）或 2（三点）2

两点公式：Pulse Delta = (2Y - 2X) / 2

12.7 差分电导模式

622x 输出差分电流扫描 dI，2182A 同步测量差分电压 dV：

  • dG = dI / dV，dR = dV / dI
  • 步进 0~105mA，延迟 1ms~9999s
