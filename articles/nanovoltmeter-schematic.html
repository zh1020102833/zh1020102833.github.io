一、系统原理图总览

``

输入端子 → 输入衰减器 → 量程继电器 → 斩波调制(SW1) → JFET差分对(JFE2140)

``

二、输入衰减器与量程切换

2.1 精密电阻网络

器件选型：VPG VHP202Z 系列或同等级精密箔电阻，0.01% 容差，2 ppm/°C 温漂。

关键参数评估

参数典型值影响分析应对策略
阻值容差0.01%衰减比精度直接决定量程精度；10mV量程÷1无衰减，影响为零；100V量程÷10000，0.01%容差产生1LSB级误差每量程单独校准，将衰减比系数存入EEPROM；生产时6位半DMM实测标定
温度系数 TC2 ppm/°C10°C变化导致20ppm偏移；100V量程下，20ppm × 100V = 2mV误差，远超纳伏级要求使用跟踪电阻网络（同一基板上4个电阻），温度系数相互抵消；关键电阻置于恒温区
长期稳定性5 ppm/年年校准周期内累积漂移可接受每12个月校准一次；使用VPG箔电阻优于厚膜电阻
热电势 EMF0.05–0.1 μV/°C跨越1°C温差产生50–100nV热电势，与70nV目标噪声相当使用同质材料连接（铜-铜）；焊接后24h老化；避免不同金属接触
电压系数 VCR<0.1 ppm/V高压量程下阻值随电压微变，100V下偏移<10ppm选箔电阻（VCR极低），避免使用厚膜电阻（VCR可达1–5 ppm/V）

原理图设计要点

  1. 每个量程的衰减器采用 T 型或 π 型网络，对称差分结构
  2. 电阻网络与继电器触点之间使用开尔文连接（4线制）
  3. 高压量程（10V、100V）的衰减器输入端增加 TVS 保护管
  4. 衰减器输出端设置 RC 预滤波（100Ω + 100nF C0G），抑制继电器切换时的高频弹跳

2.2 量程切换继电器

器件选型：Pickering 100 系列（方案已选型），热电势约 1μV。

关键参数评估

参数典型值影响分析应对策略
接触热电势~1 μV继电器触点热电势是量程切换后偏移的主要来源；1μV = 1000nV，远超测量噪声选用低热电势型号（Pickering 100系列或更优的 102系列）；继电器安装于等温块上；切换后等待热平衡（>2s）再测量
接触电阻<100 mΩ串联在信号路径上，随温度和时间漂移；100mΩ对10mV量程贡献10ppm使用4线制开尔文连接消除接触电阻影响
线圈驱动电流~15 mA @5V线圈发热导致局部温升，加剧热电势脉冲驱动后保持低功耗维持电流；线圈远离信号触点；线圈电源独立供电
切换时间<5 ms切换瞬间产生毫伏级弹跳电压切换后软件延时100ms再采样；ADC在切换期间停止转换
绝缘电阻>10^12 Ω足够高，漏电流对纳伏信号影响可忽略PCB走线保持足够爬电距离

原理图设计要点

  1. 每个继电器配备续流二极管（1N4148）和RC吸收网络（100Ω + 100nF）
  2. 继电器线圈驱动使用独立 MOSFET（如 BSS138），MCU GPIO 不直接驱动
  3. 信号路径上所有继电器触点使用对称差分连接
  4. 继电器下方 PCB 禁止布线，保持地平面完整性

三、斩波调制开关 SW1

候选器件：ADG633（方案选定）/ TMUX1133（优化建议替换）

3.1 ADG633 参数评估

参数典型值最大值影响分析应对策略
导通电阻 R_ON52 Ω75 Ω串联在JFET栅极输入端，与JFET输入电容(75pF)形成低通滤波器，f_-3dB = 1/(2π×52×75p) ≈ 41MHz，远高于信号频率，影响可忽略；但R_ON的热噪声 = √(4kTR_ON) = 0.93 nV/√Hz，直接叠加到输入等效噪声R_ON热噪声与JFE2140噪声RSS合计；R_ON随温度变化（约0.5%/°C），不影响直流精度（斩波消除）
电荷注入 Q_inj2 pC—核心问题：电荷注入产生等效偏置电流 I_bias = Q_inj × f_chop；f_chop=4kHz时，I_bias = 2pC × 4kHz = 8nA；流过源电阻R_s产生电压误差 V_err = 8nA × R_s；R_s=10Ω时V_err = 80nV，已达目标噪声量级1. 采用互补补偿开关（见下文3.3节）；2. 死区时间采样，丢弃切换后10-20μs数据；3. 评估替换为TMUX1133（Q_inj=0.17pC）
关断隔离度72 dB @1MHz—斩波半周期关断通道泄漏4kHz方波信号约-72dB，即约0.25μV（对于1V信号），除以3500增益=71pV输入等效，可忽略无需特殊处理
漏电流 I_OFF<0.2 nA—关断通道漏电流通过源阻抗产生偏移；R_s=100Ω时V_off=20nV，可忽略低源阻应用影响小
寄生电容 C_OFF2 pF—与R_ON形成关断通道RC时间常数，影响开关速度；τ = 52Ω × 2pF = 0.1ns，远快于切换速度无需特殊处理
带宽200 MHz—远高于斩波频率4kHz，信号无衰减无需特殊处理
Break-before-make 延迟8 ns—切换瞬间两通道均断开8ns，输入浮空；对4kHz斩波周期(250μs)而言占比极小(0.003%)无需特殊处理，但需确认JFET输入端无充电积累

3.3 电荷注入补偿电路设计

这是纳伏表设计中最关键的电路之一。原理图需包含以下补偿网络：

``

补偿开关

┌────────┐

SW1主开关 ──→ │ ADG633 │──→ JFET栅极

(工作时钟) │ CH1 │

└────────┘

┌────────┐

补偿开关 ──→ │ ADG633 │──→ 补偿电容 C_comp

(反相时钟) │ CH2 │

└────────┘

``

工作原理：主开关和补偿开关使用互补时钟驱动，补偿开关连接一个与JFET输入电容等值的补偿电容 C_comp ≈ 75pF。每次切换时，主开关向信号节点注入 Q_inj，补偿开关同时从信号节点抽取等量电荷，实现一阶抵消。

补偿效果：理论可降低电荷注入5–10倍，残余电荷注入约0.2–0.4 pC，等效 I_bias = 0.3pC × 4kHz = 1.2nA，在 R_s=10Ω 时仅 12nV。

C_comp 选型：使用 C0G/NP0 陶瓷电容（75pF），温漂 ±30 ppm/°C，确保全温范围内补偿效果稳定。

工作点计算：

参数计算结果

4.3 噪声优化偏置策略

R_D 热噪声：R_D = 2kΩ 时，e_n = √(4kTR) = 1.83 nV/√Hz，两只R_D合计 RSS = 2.59 nV/√Hz（差分模式）。除以差分增益120，输入等效 0.022 nV/√Hz，可忽略。

R_D 选型：使用 VPG VFR 系列箔电阻或 Susumu RG 系列薄膜电阻，0.01% 容差，2 ppm/°C。避免使用厚膜电阻（电流噪声1/f显著）。

I_DS 与噪声的关系：JFET 电压噪声近似 e_n ∝ 1/√I_DS，将 I_DS 从 1mA 提升至 2mA 可降低噪声 √2 ≈ 1.41 倍。但功耗从 10mW 增至 20mW，需考虑温升对热电势的影响。

推荐工作点：I_DS = 1.5–2 mA/侧（折中方案），R_D = 2kΩ，V_DS ≈ 6–7V。

五、斩波解调开关 SW2

器件选型：TS5A22362（方案选定）/ TMUX7234（备选）

5.2 解调开关设计要点

  1. SW2 必须与 SW1 严格同步——使用同一斩波时钟的反相信号驱动
  2. SW2 切换瞬间产生的尖峰通过 U1 的带宽限制（18MHz GBP，实际闭环带宽约1MHz）自然衰减
  3. 可在 SW2 输出端增加小 RC 缓冲器（100Ω + 1nF）进一步抑制尖峰，截止频率 1.6MHz

5.3 优化建议：TMUX7234 替代评估

TMUX7234 为 4 路 SPST 开关，电荷注入 6pC（优于 TS5A22362 的 10pC），支持 ±15V 双电源。若解调端需要处理更大信号摆幅，TMUX7234 更合适。但 TS5A22362 的超低 R_ON（0.65Ω）对信号完整性更有利。建议保持 TS5A22362 不变，解调端的电荷注入不是主要矛盾。

6.2 U1 闭环增益设计

方案原文需要U1提供约30倍闭环增益（以实现总增益3500=120×30）。建议原理图设计：

  • 反馈电阻 R_F = 29 kΩ（0.01%, 2 ppm/°C）
  • 增益电阻 R_G = 1 kΩ（0.01%, 2 ppm/°C）
  • 闭环增益 A_v = 1 + R_F/R_G = 30
  • R_G 串联 AC 耦合电容（若需要阻断JFET的DC偏移）
  • 反馈回路并联小电容 C_F ≈ 3.3 pF，限制带宽至约1.5MHz，抑制高频噪声

6.3 U1 电源去耦

  • 每个电源引脚放置 100nF C0G 电容（距离引脚<5mm）
  • 增加 10μF X7R 电容在100nF之后
  • 电源走线先经过去耦电容再到引脚

10.2 ADC 配置与斩波同步设计

核心设计原则：ADC 采样必须与斩波时钟同步。

``

斩波时钟 (4kHz)

│

├── SW1 调制（上升沿切换）

├── SW2 解调（与SW1同步）

│

└── ADC START 信号

├── 半周期 T/2 = 125μs

├── 建立/等待区: 0–15μs (丢弃)

├── 采样窗口: 15–110μs (有效)

└── 缓冲区: 110–125μs (丢弃)

``

实现方案：

  1. MCU 的定时器模块生成斩波时钟（4kHz方波）
  2. 同一定时器生成 ADC START 脉冲，延迟 15μs 后触发
  3. ADS1262 配置为脉冲模式（PULSE mode），每次 START 触发一次转换
  4. ADC 采样率由斩波时钟决定，非自由运行

ADS1262 寄存器配置建议：

寄存器值说明
MODE00x02PULSE 模式
MODE1PGA=2, SPS=20快速采样以覆盖采样窗口
MODE2Sinc³ 滤波器低噪声优选
REF外部基准, REFP0/REFN0使用 LTC6655
OFCAL校准后写入失调校准
FSCAL校准后写入增益校准

10.3 ADC 数字接口隔离

问题：EEVblog 社区已证实 ADC 数字信号（SCLK, DOUT 等）可通过 PCB 寄生电容耦合到模拟输入端，恶化噪声。

应对策略：

  1. 使用磁隔离器（如 ISO7731）隔离 ADC 的 SPI 接口
  2. ADC 转换期间（DRDY 低电平），禁止 SPI 通信
  3. SPI 时钟频率限制在 1MHz 以下（ADS1262 最高支持 8MHz，但高速时钟边沿辐射更大）
  4. 数字信号走线远离模拟输入，中间用地平面隔离
