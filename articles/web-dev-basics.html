前端开发基础：HTML 核心标签

分类：技术 · 2026-05-22

HTML（超文本标记语言）是构建网页的基础。掌握核心标签的语义化用法，是写好前端代码的第一步。

文档结构标签

每个 HTML 页面都包含标准的结构标签：

  • <!DOCTYPE html> — 文档类型声明
  • <html> — 根元素
  • <head> — 元数据区域
  • <body> — 可见内容区域

语义化标签

使用语义化标签可以让页面结构更清晰、更易维护：

  • <header> — 头部区域
  • <nav> — 导航区域
  • <main> — 主要内容区
  • <article> — 独立文章区块
  • <section> — 通用分区
  • <footer> — 底部区域
提示：合理使用语义化标签有助于 SEO 和无障碍访问。

常用内容标签

  • <h1> ~ <h6> — 标题
  • <p> — 段落
  • <a> — 链接
  • <img> — 图片
  • <ul> / <ol> — 列表
  • <table> — 表格
