语雀文章转换工作流规范

目录约定

drafts路径：C:\Users\ahs\.qclaw\workspace\yuque_export
转换后的 ：HTML 生成到这里 C:\Users\ahs\Desktop\Project\article-site\articles
图片放这里：C:\Users\ahs\Desktop\Project\article-site\image
风格模板：C:\Users\ahs\Desktop\Project\arti\技术文档风格规范.md

上述四个路径分别对应：

  • drafts — 从语雀导出的原始 Markdown 文件存放处
  • articles — 转换后的 HTML 输出目标目录
  • image — 文章引用的图片统一存放目录
  • 风格模板 — 定义 HTML 结构、CSS 变量体系、布局命名约定的参考规范

MD 文件头部格式

每篇 MD 文件必须以 YAML 头部开头，提供三要素：

---
title: 差分放大电路的构建
category: 硬件
date: 2026-05-23
description: 详细推导共射极差分放大电路的增益、CMRR及偏置设计要点
---

正文内容...
字段 说明
title 文章标题，会写入 <title> 和 <h1>
category 9 选 1：硬件 / 嵌入式 / FPGA / 高速信号 / EMC / 控制理论 / 电机 / EDA / 随笔
date 日期，格式 YYYY-MM-DD
description 一句话简介，显示在首页卡片

自动化流程

询问用户需要路径下的哪个根目录
→ 用户确认
→ 自动触发转换
→ 调用风格模板
→ HTML 写入 articles/
→ 自动运行 scripts/scan-articles.py
→ 自动 git push

Markdown 中的图片路径：../image/文章名-N.jpg 转换为 HTML 时保持不变。
